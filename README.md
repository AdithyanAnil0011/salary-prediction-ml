# Salary Prediction using Machine Learning

## Project Overview

This project focuses on predicting salary categories using Machine Learning algorithms. The project includes data preprocessing, feature engineering, model training, and evaluation using multiple classification models.

The objective of this project is to understand the practical workflow of Machine Learning and compare the performance of different algorithms on the same dataset.
